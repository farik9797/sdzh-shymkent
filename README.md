# Совет деловых женщин города Шымкент — сайт

Одностраничный сайт общественного объединения «СДЖ Шымкент»: наставничество, финансирование
и инвестиции, B2B и закупки, экспорт и цифровизация для женского предпринимательства.

Планируемый домен — `sdzh-shymkent` (зона уточняется).

## Стек

Статический HTML без сборки: шесть страниц с общими `assets/style.css` и `assets/app.js`.
Из внешнего — только шрифт Manrope с Google Fonts и anime.js с CDN для входной анимации
главной (подгружается динамически и не грузится вовсе при `prefers-reduced-motion`).

- Reveal-анимации — IntersectionObserver + CSS-переходы. Без JS весь контент остаётся видимым.
- FAQ — нативный `<details>`, скриптом держится открытым один пункт.
- Иконки — SVG-спрайт: Lucide (интерфейс) и Simple Icons (соцсети).
- Формы работают по общему механизму: обязательные поля берутся из `[required]`,
  блок успеха указывается атрибутом `data-lead`. Добавить форму можно одной разметкой.

## Структура

```
index.html          главная
about.html          о Совете
directions.html     направления работы
resource.html       ресурсный центр «IS QOLDAY»
events.html         мероприятия
news.html           новости (список)
news-article.html   шаблон публикации — копируется для каждой новости
contacts.html       контакты
privacy.html        обработка персональных данных (черновик, требует утверждения)

assets/style.css    общие стили всех страниц
assets/app.js       общий скрипт всех страниц
assets/             логотип и фотографии
PROGRESS.md         рабочая память: решения, ограничения, открытые вопросы
```

Шапка, подвал и модальное окно продублированы в каждой странице — это обычная цена
статической вёрстки без сборщика. При переносе в WordPress они станут `header.php`
и `footer.php`, и дубли исчезнут. Пока правку в шапке нужно повторить в девяти файлах.

## Фирменные цвета

Сняты пипеткой с логотипа заказчика, а не подобраны на глаз.

| Роль | HEX | Контраст |
|---|---|---|
| Бренд-синий | `#004D93` | 8.46:1 на белом — годится для текста и ссылок |
| Золото | `#F3AA06` | 1.99:1 на белом — **только графика**; 6.78:1 на `#0A2E5C` |
| Тёмно-синий фон | `#0A2E5C` | белый текст 13.48:1 |
| Текст | `#1F2630` | 15.24:1 на белом |

Бриф требует строгий официальный минимализм и прямо запрещает розовый, цветы, женские силуэты,
яркие градиенты и клипарт. Логотип содержит стилизованный цветок-орнамент — это бренд, он остаётся;
запрет касается декоративных добавлений.

## Состояние контента

- **Hero сделан photo-ready.** Бриф требует реальные деловые фотографии без глянца; пока их нет,
  фон — строгая штриховка. Слот под снимок размечен комментарием в разметке.
- **Раздел новостей — заглушки** с описанием рубрик, без выдуманных дат и заголовков.
- **Суммы взносов и число участниц на сайт намеренно не вынесены** — бриф разрешает публиковать
  их только после официального утверждения и сверки актуальности. Подробности в `PROGRESS.md`.

Осталось получить от заказчика: доменную зону, e-mail, реальные фотографии,
утверждённые условия членства и актуальные показатели.

## Локальный запуск

Сборка не нужна:

```bash
open index.html
```

## Референс дизайна

Композиция главной ориентирована на шаблон Keywordly (html.designingmedia.com/keywordly/index1.html).
Использована только структура: палитра, тон и типографика взяты из брифа, код написан с нуля.
Сам коммерческий шаблон в репозиторий не входит.
